# Cplusplus

This repository contains a collection of C++ projects and exercises, organized into different categories.

## Project Structure

- **BinaryTree**: Implementation and exercises related to binary trees.
- **C++advanced**: Advanced C++ concepts and examples.
- **C++basic**: Fundamental C++ concepts and examples.
- **Class**: Examples of C++ classes and object-oriented programming.
- **DP**: Dynamic programming exercises.
- **FIND**: Searching algorithms and exercises.
- **GreedyAlgorithm**: Greedy algorithm exercises.
- **HUAWEI**: Solutions to Huawei programming contest problems.
- **Map**: Exercises related to maps and hash tables.
- **MathQuestions**: Mathematical programming problems.
- **NewCode**: Various programming exercises.
- **Nnuo**: Exercises from Nanjing Normal University Online Judge.
- **OOP**: Object-oriented programming examples.
- **PriorityQueue**: Exercises related to priority queues.
- **SORT**: Sorting algorithms and exercises.
- **String**: String manipulation exercises.
- **Vector**: Exercises related to vectors.
- **externC**: Examples of using `extern "C"` to link C and C++ code.
- **release**: Compiled executable files.
- **simulate**: Simulation exercises.

## How to Use

Each folder contains specific C++ projects or exercises. You can browse the folders to find examples of different algorithms, data structures, and C++ features. The `release` folder contains compiled executables for some of the projects.
